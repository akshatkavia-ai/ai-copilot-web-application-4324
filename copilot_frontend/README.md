# AI Copilot Frontend (React + Vite)

React frontend for AI Copilot chat app.

## Setup

1) Install dependencies:
   npm install

2) Create env from example:
   cp .env.example .env

3) Start dev server (http://localhost:3000):
   npm run dev

The frontend expects the backend running at http://localhost:3001 (configurable via VITE_API_BASE).

## Env

- VITE_API_BASE (default http://localhost:3001/api)
